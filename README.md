# StudentCalc — Class 1–12 Student Calculator

A clean, responsive all-in-one calculator for students from Class 1 to 12.

## Features
- Basic calculator and keyboard support
- Percentage and average tools
- Geometry calculator
- Advanced functions: square root, trigonometry, logarithms, powers
- Formula reference library
- Calculation history using local storage
- Light/dark mode
- Mobile responsive design

Open `index.html` directly or deploy the repository with GitHub Pages.
